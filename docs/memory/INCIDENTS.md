# Memória de incidentes e correções

Este arquivo registra erros para evitar repetição e regressão.

## Formato obrigatório
Para cada incidente:
- ID e data
- Sintoma
- Causa raiz
- Impacto
- Arquivos/fluxos afetados
- Correção
- Commit/PR
- Teste de reprodução
- Evidência de passagem
- Regra preventiva
- Limitações

## Registros históricos
Ainda não há incidentes certificados nesta auditoria remota. Relatos anteriores devem ser adicionados somente com evidência ou marcados como “relatado, pendente de verificação”.

Não apagar registros antigos. Complementar quando novas evidências surgirem.
